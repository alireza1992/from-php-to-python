## Goal

1- Registration process from start to end.

2- Add more behaviours in player domain.

3- Avoid importing FastAPI outside of application and sqlalchemy outside of infrastructure.

4- Be able to answer who own playerRegistration?! 

## Plan

1- Pass the request through some simple middlewares like csrf

2- Validate using pydantic models, create a DTO or value objects for inputs.

3- Use DDD , useCase to orchestrate the flow from controller to repository, add behaviours to player entity.

4- Use repository pattern to abstract the database

5- Use unit of work pattern to ensure atomicity

6- Map the request to the domain model

7- Use the presentation schemas for both request and response
